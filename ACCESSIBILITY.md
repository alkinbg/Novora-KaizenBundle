# Accessibility

Novora KaizenBundle aims to keep its administrator interface usable with keyboard navigation, semantic HTML, visible form labels, and readable error feedback.

## Supported usage

The UI is server-rendered and does not require JavaScript for its basic investigation forms. Form validation messages should be available as text, not only as color.

## Known limitations

A formal WCAG conformance audit has **not** been completed; we do not claim WCAG certification. Some charts and dense diagnostic views may still require usability improvements, including better nonvisual alternatives.

## Reporting barriers

Open an [accessibility issue](https://github.com/alkinbg/Novora-KaizenBundle/issues/new/choose) with the affected page, keyboard or assistive technology used, expected behavior, and reproduction steps. Do not include real log messages or sensitive production data.
