# Support

## Questions and usage

Start with the [README](README.md) for installation, supported versions, and configuration. The [guided demonstration](docs/DEMO.md) explains the intended investigation workflow.

For reproducible bugs or focused improvements, use [GitHub Issues](https://github.com/alkinbg/Novora-KaizenBundle/issues) and the corresponding templates.

This is a community-maintained open-source package. No response time, service-level agreement, hosted monitoring, or commercial support is promised.

## Security

**Do not open public issues with vulnerabilities or private diagnostic information.** Follow [SECURITY.md](SECURITY.md) for private reporting.

## Data safety

Use anonymized or synthetic logs in reports. The UI is an administrator tool and its best-effort redaction is not a guarantee that every secret can be removed.
